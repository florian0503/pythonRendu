Analyse et Stratégies pour les Cinémas

Présentation du projet

Ce projet a pour objectif d’analyser la performance des cinémas en France à l’aide de données existantes et de fournir des recommandations pour améliorer leur fréquentation. Les étapes clés incluent :

Le traitement et la préparation des données.
L’analyse descriptive et la création de visualisations.
La construction d’un modèle prédictif basé sur une régression linéaire pour estimer les entrées.
Des propositions stratégiques fondées sur les prédictions du modèle.

Instructions d'exécution
Installer les dépendances :

pip install -r requirements.txt  

Lancer le script principal :

python main.py
